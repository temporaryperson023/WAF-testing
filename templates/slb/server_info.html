Key Headers Haltdos Adds
X-Forwarded-For — The real client IP before it passed through Haltdos. Without this your backend only sees Haltdos's IP.
X-Real-IP — Single real client IP — cleaner than X-Forwarded-For for logging.
X-Forwarded-Proto — Whether the original request was HTTP or HTTPS — important for redirect logic.
Host — The original hostname the client requested — needed when one backend serves multiple domains.
User-Agent — Passed through from the client — Haltdos uses this for bot detection rules.

Haltdos tip — In production, your backend app should always read X-Forwarded-For instead of the raw client IP for logging and rate limiting — because the raw IP will always be Haltdos's internal IP, not the real user's IP.
