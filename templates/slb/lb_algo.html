Algorithm Guide
RR
Round Robin
Request 1 → server-01, Request 2 → server-02, Request 3 → server-03, Request 4 → server-01 again. Good for servers with equal capacity.
LC
Least Connections
Sends each new request to whichever server is currently handling the fewest connections. Best when requests have varying response times.
IH
IP Hash
Hashes the client's IP address to always route them to the same server. Provides natural session stickiness without cookies.
WR
Weighted Round Robin
Like Round Robin but servers with higher weight receive proportionally more requests. Use when servers have different CPU/RAM capacity.
RN
Random
Picks a server randomly. Simple and works well when all servers are identical and stateless.
Haltdos tip — In the Haltdos console go to ADC → Listeners → Server Groups → Load Balancing to set the algorithm. Changes take effect immediately without restarting the listener.
