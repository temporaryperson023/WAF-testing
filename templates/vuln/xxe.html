High OWASP A05 — Security Misconfiguration

XXE Injection

This endpoint parses XML with resolve_entities=True and no network restrictions. A crafted <!DOCTYPE> block can define an external entity pointing to any local file — the parser reads it and returns the contents in the response.

XML Input
{% if result %}
XML Parsed Successfully
{% for tag, value in result.items() %} {% endfor %}
Tag Value
{{ tag }} {{ value }}
{% endif %} {% if error %}
Parser Error
{{ error }}
{% endif %}
Why this is vulnerable — The parser is initialized as:

etree.XMLParser(resolve_entities=True, no_network=False)

resolve_entities=True tells the parser to fetch and substitute external entities. A WAF should block any XML body containing <!DOCTYPE, <!ENTITY, or the SYSTEM keyword.
